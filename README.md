Smart Complaint & Issue Tracking System

Project Description

Smart Complaint & Issue Tracking System is a Python-based console application used to manage and track employee complaints and technical issues.

It allows users to create, view, search, update, and delete tickets. Ticket information is stored permanently using a JSON file.

Features

- Create new complaint tickets
- Automatically generate unique Ticket IDs
- View all tickets
- Search tickets
- Update ticket status
- Update ticket priority
- Delete individual tickets
- Generate category reports
- Generate summary reports
- Delete all tickets
- Store data using JSON file handling
- Input validation

Technologies Used

- Python
- JSON

Python Concepts Used

- Functions
- Lists and Dictionaries
- Conditional Statements
- Loops
- File Handling
- Exception Handling
- Input Validation

How to Run

1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

python main.py
